# Iris Flower Classification

## Project Overview
This project uses Machine Learning to classify Iris flowers
into three species based on their measurements.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
The Iris dataset contains flower measurements such as
sepal length, sepal width, petal length, and petal width.

## Algorithm
Random Forest Classifier

## Steps
1. Load the Iris dataset.
2. Split the dataset into training and testing data.
3. Train the machine learning model.
4. Predict flower species.
5. Evaluate model accuracy.
6. Visualize the flower measurements.

## Results
The model predicts Iris flower species using their measurements.
See the notebook for the actual accuracy and evaluation results.
