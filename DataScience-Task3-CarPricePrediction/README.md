# Car Price Prediction with Machine Learning

## Project Overview
This project predicts the selling price of used cars
using Machine Learning techniques in Python.

## Objective
To build a regression model that estimates car selling
prices based on different car features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Load the dataset.
2. Explore and clean the data.
3. Perform Exploratory Data Analysis (EDA).
4. Visualize car prices and related features.
5. Encode categorical variables.
6. Split data into training and testing sets.
7. Train a Linear Regression model.
8. Evaluate the model using MAE, RMSE, and R².
9. Predict car selling prices.

## Model Evaluation
The model was evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Conclusion
This project demonstrates how Machine Learning
can be used to estimate used-car selling prices
based on available vehicle features.
